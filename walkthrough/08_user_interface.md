# User Interface in Bitcoin v0.2.0

The user interface (UI) in Bitcoin v0.2.0 is built using the wxWidgets cross-platform GUI framework. It provides users with access to wallet operations, transaction management, network status monitoring, and the unique (at the time) integrated marketplace features.

*Relevant files:*
*   `ui.h`: Contains declarations for UI-related classes, event types, and global UI variables.
*   `ui.cpp`: Implements the application logic for the UI, event handlers, and custom behaviors for dialogs and frames.
*   `uibase.h`: Contains declarations for base UI classes, likely generated by a GUI builder tool (wxFormBuilder).
*   `uibase.cpp`: Implements the basic structure and layout of UI elements, also likely generated.
*   `changelog.txt`: (Previously read) Contains notes on UI improvements in this version.
*   Resource files like `rc/bitcoin.ico`, `rc/addressbook16.bmp`, and various XPMs in `xpm/` (e.g., `send20.xpm`) provide icons and graphics.

## UI Architecture Overview

The UI layer interacts with the core Bitcoin logic to present information to the user and to translate user actions into operations on the blockchain, wallet, or network.

*   **wxWidgets**: The choice of wxWidgets allows for a cross-platform application that can run on Windows, Linux (GTK), and macOS.
*   **Event-Driven**: The UI is event-driven, responding to user inputs (mouse clicks, key presses) and system events (timers, network updates).
*   **Custom Events**: Custom event types like `wxEVT_UITHREADCALL`, `wxEVT_REPLY1`, etc., are defined for inter-thread communication and asynchronous operations.
    *Defined in [ui.h Lines 9-12](https://github.com/jonzou/btc020/blob/ebbdade7/ui.h#L9-L12)*
*   **Main Application Class (`CMyApp`)**: Inherits from `wxApp` and handles application initialization, global settings, and top-level exception handling.
    *Implemented in [ui.cpp Lines 1111-1393](https://github.com/jonzou/btc020/blob/ebbdade7/ui.cpp#L1111-L1393)*
*   **Main Frame (`CMainFrame`)**: The primary window of the application, derived from `CMainFrameBase`.
    *Implemented in [ui.cpp Lines 124-705](https://github.com/jonzou/btc020/blob/ebbdade7/ui.cpp#L124-L705)*
    *Base class `CMainFrameBase` in [uibase.h](https://github.com/jonzou/btc020/blob/ebbdade7/uibase.h#L20-L146) and [uibase.cpp](https://github.com/jonzou/btc020/blob/ebbdade7/uibase.cpp#L13-L210)*

## Core UI Components and Dialogs

Bitcoin v0.2.0 features several dialogs for various user interactions:

### 1. Main Window (`CMainFrame`)
*   Displays the current balance (`m_staticTextBalance`).
*   Shows a list of all transactions (`m_listCtrl`) with columns for status, date, description, debit, and credit.
    *Column setup in [ui.cpp Lines 299-305](https://github.com/jonzou/btc020/blob/ebbdade7/ui.cpp#L299-L305)*
*   Provides a toolbar with "Send Coins" and "Address Book" buttons.
*   Displays the user's current Bitcoin address (`m_textCtrlAddress`) with a "Copy to Clipboard" button.
*   Includes a status bar showing connection count, block count, transaction count, and generation status.
*   Handles application close events (`OnClose`), potentially minimizing to tray.
*   Manages system tray icon (`CMyTaskBarIcon`).

### 2. Options Dialog (`COptionsDialog`)
*Allows users to configure various settings. Derived from `COptionsDialogBase`.*
*Implemented in [ui.cpp Lines 771-918](https://github.com/jonzou/btc020/blob/ebbdade7/ui.cpp#L771-L918)*
*Base class `COptionsDialogBase` in [uibase.h](https://github.com/jonzou/btc020/blob/ebbdade7/uibase.h#L186-L264) and [uibase.cpp](https://github.com/jonzou/btc020/blob/ebbdade7/uibase.cpp#L248-L385)*
*   **Settings include**:
    *   Transaction fee (though typically 0 in this version).
    *   Coin generation processor limit.
    *   Start Bitcoin on system startup (`SetStartOnSystemStartup` for Windows).
        *Implemented in [ui.cpp Lines 1400-1451](https://github.com/jonzou/btc020/blob/ebbdade7/ui.cpp#L1400-L1451)*
    *   Minimize to tray / Minimize on close.
    *   SOCKS4 proxy configuration (IP and port).
*   Settings are saved to `wallet.dat` using `CWalletDB::WriteSetting()`.

### 3. Send Coins Dialog (`CSendDialog`)
*Used to create and send Bitcoin transactions. Derived from `CSendDialogBase`.*
*Implemented in [ui.cpp Lines 952-1108](https://github.com/jonzou/btc020/blob/ebbdade7/ui.cpp#L952-L1108)*
*Base class `CSendDialogBase` in [uibase.h](https://github.com/jonzou/btc020/blob/ebbdade7/uibase.h#L296-L367) and [uibase.cpp](https://github.com/jonzou/btc020/blob/ebbdade7/uibase.cpp#L423-L516)*
*   Fields for Pay To (address), Amount.
*   Can access Address Book (`OnButtonAddressBook`).
*   If a Bitcoin address is entered, message fields are disabled.
*   If an IP address is entered (for direct IP-to-IP transaction, a feature later removed):
    *   Fields for From (sender alias) and Message are enabled.
    *   A `CSendingDialog` is shown to manage the connection and transfer process.

### 4. Sending Dialog (`CSendingDialog`)
*Modal dialog shown during direct IP-to-IP transfers. Derived from `CSendingDialogBase`.*
*Implemented in [ui.cpp Lines 1117-1300](https://github.com/jonzou/btc020/blob/ebbdade7/ui.cpp#L1117-L1300)*
*Base class `CSendingDialogBase` in [uibase.h](https://github.com/jonzou/btc020/blob/ebbdade7/uibase.h#L369-L405) and [uibase.cpp](https://github.com/jonzou/btc020/blob/ebbdade7/uibase.cpp#L518-L568)*
*   Handles the two-step process for IP-to-IP transactions:
    1.  `checkorder`: Sends the order details (amount, message) to the recipient. The recipient replies with a public key for payment.
        *Handled by `CSendingDialog::StartTransfer` and `CSendingDialog::OnReply2` via custom events.*
    2.  `submitorder`: Sends the actual transaction (paying to the public key received) to the recipient for verification.
        *Handled by `CSendingDialog::OnReply2` and `CSendingDialog::OnReply3`.*
*   Provides status updates to the user during this process.

### 5. Address Book Dialog (`CAddressBookDialog`)
*Manages a list of saved Bitcoin addresses and their labels (for sending). Derived from `CAddressBookDialogBase`.*
*Implemented in [ui.cpp Lines 1495-1619](https://github.com/jonzou/btc020/blob/ebbdade7/ui.cpp#L1495-L1619)*
*Base class `CAddressBookDialogBase` in [uibase.h](https://github.com/jonzou/btc020/blob/ebbdade7/uibase.h#L460-L509) and [uibase.cpp](https://github.com/jonzou/btc020/blob/ebbdade7/uibase.cpp#L606-L668)*
*   Lists Name and Address.
*   Allows adding new addresses, editing labels, and deleting entries.
*   Address book data is stored in `wallet.dat` via `CWalletDB::WriteName()` and `EraseName()`.
*   If opened for sending (`fSending = true`), double-clicking an address populates the Send Coins dialog.

### 6. Your Receiving Addresses Dialog (`CYourAddressDialog`)
*Manages the user's own Bitcoin addresses for receiving payments. Derived from `CYourAddressDialogBase`.*
*Implemented in [ui.cpp Lines 1309-1404](https://github.com/jonzou/btc020/blob/ebbdade7/ui.cpp#L1309-L1404)*

*   Lists Label and Bitcoin Address.
*   Allows creating new addresses (`GenerateNewKey()`) and labeling them.
*   The selected address here becomes the "default key" displayed in the main window.
    *Default key stored via `CWalletDB().WriteDefaultKey(keyUser.GetPubKey())`.*

### 7. Transaction Details Dialog (`CTxDetailsDialog`)
*Displays detailed information about a selected transaction. Derived from `CTxDetailsDialogBase`.*
*Implemented in [ui.cpp Lines 711-879](https://github.com/jonzou/btc020/blob/ebbdade7/ui.cpp#L711-L879)*

## UI Enhancements in v0.2.0 (from `changelog.txt`)
*   **Options Dialog Layout Change**: Added a UI options panel.
*   **Minimize to Tray**: Feature to minimize the application to the system tray.
    *Handled in `CMainFrame::OnIconize` and `CMyTaskBarIcon`.*
*   **Startup on System Boot**: Option to start Bitcoin automatically.
    *Implemented in `SetStartOnSystemStartup` (Windows-specific using shell links/shortcuts).
*   **Ask Before Closing**: Confirmation dialog before exiting.
    *Handled in `CMainFrame::OnClose` via `fMinimizeOnClose`.*
*   **NSIS Installer**: Provided a professional installer for Windows.
